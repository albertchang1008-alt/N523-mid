# 🌟 N523 護理科・AI 智能輔導問卷系統 (完整部署指南)

這是一套專為護理科設計的「學習輔導問卷系統」。整合了全科成績總覽、日常作息追蹤、讀書方法分析，並導入 **Google Gemini AI 進行「二階段動態追問」**，幫助老師深入了解學生的學習狀況與家庭支持，有效提升輔導面談的品質。

## 📂 檔案清單與用途

1. **`Code.gs`**：系統後端核心。負責連接 Google 試算表與呼叫 Gemini AI。需部署於 Google Apps Script。
2. **`Index.html`**：學生端問卷。提供成績快覽、反思填寫與 AI 追問互動。
3. **`Dashboard.html`**：教師端後台。包含各式統計圖表、高風險預警名單、AI 面談建議與家長回饋對照。
4. **`Parent.html`**：家長端問卷。透過專屬連結免密碼登入，供家長查看學生現況並提供觀察回饋。

## ⚠️ 舊版升級特別注意事項 (必讀)

如果您是從舊版本升級，因為這次我們**新增了非常多資料欄位**（作息、讀書方法、AI追問紀錄等），請務必執行以下操作，否則資料會錯位： 👉 **請到您的 Google 試算表中，將舊的「問卷回饋表」與「家長回饋表」整頁刪除（或重新命名為舊檔備份）。**

> 系統在收到新問卷時，會自動幫您建立帶有「最新正確欄位標題」的全新工作表。

## 🚀 系統部署教學 (Step-by-Step)

### 第一步：準備 Google 試算表 (資料庫)

1. 新建一個 Google 試算表。
2. 建立以下 **5 個工作表**（名稱必須一字不差）：
   - `班級成績總表`
   - `問卷回饋表`
   - `家長連結`
   - `家長回饋表`
   - `教師帳號`
3. **設定教師帳號**：在 `教師帳號` 工作表中填入登入資訊：
   - A1 欄填寫帳號 (例：`admin`)
   - B1 欄填寫密碼 (例：`123456`)
   - C1 欄填寫顯示名稱 (例：`張欣翰`)
4. **匯入成績**：在 `班級成績總表` 匯入成績（預設邏輯：第5列為科目名稱、第6列開始為學生資料、B欄為學號、C欄為姓名、D欄起為各科成績）。

### 第二步：部署 Google Apps Script (後端)

1. 在剛剛的試算表中，點擊上方選單的 **「擴充功能」 -> 「Apps Script」**。
2. 將 `Code.gs` 的完整內容貼上並儲存。
3. **[強烈建議] 填寫 Gemini API Key**：
   - 到 [Google AI Studio](https://aistudio.google.com/app/apikey) 免費申請一把 API Key。
   - 貼到程式碼第 7 行的 `GEMINI_API_KEY: "您的金鑰",` 之中。
4. 點擊右上角 **「部署」 -> 「新增部署作業」**。
   - 類型選擇：**「網頁應用程式」**
   - 執行身分：**「我」**
   - 存取權：**「知道連結的任何人」**
5. 點擊部署後，複製那串 **「網頁應用程式 URL」** (格式為 `https://script.google.com/macros/s/XXXXX/exec`)。

### 第三步：綁定前端網頁 API

1. 使用文字編輯器（如 VS Code 或記事本）打開 `Index.html`、`Dashboard.html`、`Parent.html`。
2. 滑到檔案最下方，找到 `<script>` 區塊的第一行：

   ```
   const API = "[https://script.google.com/macros/s/XXXXXXXXX/exec](https://script.google.com/macros/s/XXXXXXXXX/exec)";
   ```
3. 將裡面的網址**替換成您在第二步取得的專屬網址**，儲存檔案。

### 第四步：發布前端網站與最終設定

1. 將改好 API 的三個 HTML 檔案上傳到您的網頁空間（例如 GitHub Pages）。
2. **設定家長連結網址**：
   - 取得上傳後 `Parent.html` 的公開網址（例如：`https://您的帳號.github.io/專案/Parent.html`）。
   - 回到 Apps Script (`Code.gs`)，將該網址填入第 6 行的 `PUBLIC_PARENT_URL: "...",`。
3. **重新部署後端**：
   - 在 Apps Script 點擊右上角 **「部署」 -> 「管理部署作業」**。
   - 點擊右上角鉛筆圖示 (編輯) -> 版本選擇 **「新版本」** -> 點擊儲存。

## 🧪 系統測試流程建議

部署完成後，您可以依照以下順序自行測試系統是否正常運作：

1. **👨‍🎓 測試學生問卷**：
   - 打開您發布的 `Index.html`。
   - 輸入在「班級成績總表」中確實存在的一筆「學號」與「姓名」。
   - 體驗填寫反思、作息、盲點，按下「下一步」測試 AI 助教的「動態追問」是否正常彈出。
2. **👨‍🏫 測試教師後台**：
   - 打開您發布的 `Dashboard.html`。
   - 使用您在試算表設定的帳密登入（例如 `admin` / `123456`）。
   - 點擊剛填完問卷的學生姓名，測試「成績快覽 Modal」與查看「學生對照分析」。
3. **👨‍👩‍👧 測試家長連結**：
   - 在教師後台左側點選「發送家長連結」。
   - 找到剛剛那位學生，點擊「產生連結」並複製網址。
   - 在新分頁打開該網址，確認是否能直接看到該學生的作息、盲點與 AI 對話，並測試家長端的回填功能。

> **💡 維護提示**： 若您未來想修改後台登入網址的防護權杖，可於 `Code.gs` 修改 `DASHBOARD_TOKEN` 的值，並在進入後台時於網址後方加上 `?token=您的新密碼`。若發生任何錯誤，請檢查試算表工作表名稱是否被更動，或重新執行 Apps Script 的「新增版本」部署。
